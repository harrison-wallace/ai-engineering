# review-website-design

Evaluate a website (live URL, local app, mockup, or described design) against the
psychology-of-premium-websites framework. Full source framework with the trends
table and delivery model: [premium-website-framework.md](premium-website-framework.md).

## 1. Establish what's being reviewed

Identify the subject: a URL, a local project (find and inspect the pages/
components/styles — or run it and screenshot if tooling allows), or a design
being discussed. If reviewing code only, say so — some checks (load feel,
animation timing) need the rendered site, mark those ❓. If the subject is
genuinely unclear, ask; otherwise state it in one sentence and proceed.

## 2. Assess against the framework

Work through the sections **in order** — that's the order the framework is
applied in. For each, answer the checks honestly; "unknown" is a valid answer.

### Step 1 — First Impression (Halo Effect)

First impression forms in ~50 ms and colors everything after.

- Is there one defined emotion the first 50 ms should evoke? Does the hero
  deliver it — clean, confident, zero clutter?
- Bespoke assets only: no generic stock photos or free icon libraries; custom
  graphics that break up content and match brand tone.
- Brand foundation locked: professional logo, cohesive mood-setting palette,
  sophisticated readable fonts (nothing childish, outdated, or hard to read).
- Test: does it instantly read as "someone who cares about details built this"?

### Step 2 — Cognitive Load (Fluency)

Effortless comprehension builds trust.

- Everything unnecessary removed; generous white space; one primary goal per
  section.
- Navigation: 3 clicks max to anything; clear site architecture where every
  page has a purpose and leads somewhere.
- CTAs obvious and easy to find (never buried in the footer).
- Internal linking and structure serve both humans and SEO/AIO; no dead ends
  or rage-click traps.
- Test: does a first-time visitor understand the site and know what to do next
  in under 10 seconds?

### Step 3 — Micro-Interactions (Peak-End Rule)

People remember peaks and the ending.

- Audit every button, form, scroll, page load, menu, and hover for opportunity.
- Animations subtle and purposeful only — fade-ins on scroll, natural hover
  responses, smooth section entrances. Never flashy; they must reduce
  confusion and guide attention.
- Test: does the user feel calm, guided, and delighted — at least 5 delightful
  micro-moments?

### 2026 Trends layer

Only after the three steps are solid. Check which of these are used well,
misused, or missed opportunities (see the reference for the full table):
human-made design, strategic design thinking, organic/anti-grid layouts,
motion narrative, glassmorphism 2.0, archival index density, purposeful
micro-interactions, accessibility-first, AI as creative partner (ideation/
optimization only), performance-first (fast = trustworthy).

### Delivery & Ownership (when reviewing a client project)

Skip this section if there's no client handover in scope.

- Client can own and update the site themselves — intuitive CMS, no black-box
  code.
- Handover includes recorded training (plus optional live session), 30 days
  post-launch email support, optional maintenance plan.

## 3. Report

Output one table, then a short verdict:

| Area | Status | Finding |
|---|---|---|
| Halo / First Impression | ✅ / ⚠️ / ❌ / ❓ | One or two sentences: what's strong or missing. |
| Cognitive Fluency | … | … |
| Micro-Interactions | … | … |
| 2026 Trends | … | … |
| Delivery & Ownership | … | … (or "n/a — no handover in scope") |

- ✅ solid, ⚠️ partially there, ❌ missing or violates the framework,
  ❓ can't judge from what's available (say what's needed to judge it).
- After the table: the single highest-leverage fix for each ⚠️/❌ row — a
  concrete change, not a restatement of the principle.
- Close with one line of overall verdict (e.g. "Premium once the hero and CTA
  placement are fixed."). If everything is solid, say so and stop.
- **Do not implement anything** — this skill assesses and recommends. The user
  decides what to act on.
